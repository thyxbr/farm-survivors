# Genre: RPG Family

Region identity. Quest hubs. Loot rarity visual language. Class-readable gear.

## This Project (godot-3d)

Follow `../references/godot-3d-pipeline.md` first: models are built by Python scripts in `tools/blender/` run via Blender CLI, flat-colour materials, no UVs/textures, pivot empties instead of armatures, and part names used by `scripts/` must not change.
