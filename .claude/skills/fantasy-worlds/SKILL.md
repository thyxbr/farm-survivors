# Fantasy Worlds

Pick fantasy subgenre and keep material language consistent.

## This Project (godot-3d)

Follow `../references/godot-3d-pipeline.md` first: models are built by Python scripts in `tools/blender/` run via Blender CLI, flat-colour materials, no UVs/textures, pivot empties instead of armatures, and part names used by `scripts/` must not change.

## Subgenres
Medieval low-magic · High fantasy · Dark fantasy · Urban fantasy

## Tenets
1. Material honesty (wood/stone/leather/magic emissive rules)
2. Silhouette heraldry readable
3. Magic FX gated by `vfx-fx`
4. Architecture matches tech level
