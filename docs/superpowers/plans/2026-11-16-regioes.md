# Regiões de monstros com nome no mapa: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mapas com regiões nomeadas (nó `MapRegion` + `data/balance/regions.json`) que dão o nível dos monstros,
aparecem no mapa/atlas/minimapa, avisam na entrada e podem ser citadas pelas missões; Vale ~120 monstros e os outros
mapas ~60 em bandos.

**Architecture:** A forma e a posição de cada região vêm dos nós `MapRegion` das cenas, lidas pela `MapData` como os
landmarks (puro, com cache). Os números (nome, faixa, densidade, aparece no mapa) vêm do `regions.json`. `Regions`
ganha consultas puras (`area_at`, `area_info`, `area_label`, `spawn_range`) que recebem a tabela por parâmetro; o
lado do jogo (MapLoader, HUD, mapas) passa `Balance.tables.get_table("regions")`.

**Tech Stack:** Godot 4.7 / GDScript; testes unitários `tests/unit/run.gd`, `smoke_test`, `net_test` (skill smoke-check).

**Spec:** `docs/superpowers/specs/2026-11-16-progressao-design.md`, seção "2. Regiões de monstros com nome no mapa" e
seção 0. Nomes das regiões aprovados pelo usuário em 2026-11-16 (tabela na Task 1).

## Global Constraints

- Todo número de balanceamento editável no Godot: `data/balance/regions.json` ou Inspector do `MapRegion`/`EnemySpawn`.
- Classes puras (`Regions`, `MapData`, `MapRules`, `CharRules`, `StoryRules`) não citam autoload (`Balance`, `Game`...).
- Solo e online iguais (servidor autoritativo); o nível do monstro continua indo pela rede, não é recalculado no cliente.
- `EnemySpawn.level > 0` (Parte 1) continua mandando; `level = 0` dentro de região usa a faixa da região; fora de
  região continua `ref_level` (nível 0 → `ProgressionRules.spawn_level` devolve 0).
- Missões sem `region` continuam iguais. Saves antigos continuam carregando (nada novo no save).
- Horda e Defesa da Cidade inalteradas.
- PR sobe `config/version` (0.30.0 → 0.31.0).

## Review Focus

- Regiões sobrepostas (Ameias do Lich × Cume Maldito): `area_at` devolve a de **menor área** → teste na Task 1.
- `region_id` do nó que não existe no `regions.json`: validação do mapa acusa, e `area_info` devolve padrão (nome =
  id, sem faixa) sem quebrar → testes nas Tasks 1 e 3.
- Missão com `region` e monstro do mesmo tipo fora da região: não conta; mesmo tipo dentro conta; missão sem `region`
  conta em qualquer lugar → teste na Task 5.
- Aviso de entrada: andar dentro da mesma região, ou sair para "nenhuma", não repete o letreiro; voltar depois mostra
  de novo → teste puro na Task 4.
- Servidor com ~300 monstros: medir `--netstats` antes/depois (Task 6); se o tick piorar muito, monstros longe de todo
  jogador param a IA.

  `scripts/map/map_validation.gd`

**Interfaces (produz):**
- `regions.json`: `{id: {"name", "level_min", "level_max", "density", "show_on_map"}}` na ordem abaixo.
- `MapRegion` (`@tool`, `class_name MapRegion`, Node3D): `region_id: String`, `shape` (`@export_enum("Retângulo",
  "Disco")`, 0/1), `size: Vector2` (largura X × profundidade Z, rect), `radius: float` (disco), `follow_ground := true`.
  Rotação Y do nó gira o retângulo. Prévia: contorno/disco translúcido + rótulo "Nome · Nv a–b" (lê o JSON direto
  do arquivo no editor, como `MapData.enemy_kinds`).
- `MapData.areas(map_id) -> Array` de `{"id", "map", "center": Vector3 global, "shape": 0|1, "size": Vector2,
  "radius": float, "rot": float}`, com cache (lido junto com os landmarks: uma só leitura da cena por mapa).
- `MapData.all_areas() -> Array` (todos os mapas de `Regions.ORDER`).
- `Regions.area_has(a: Dictionary, pos: Vector3) -> bool`
- `Regions.area_at(pos: Vector3) -> String` ("" = fora; várias contendo → menor área). Vários nós com o mesmo id
  formam uma região só.
- `Regions.area_center(id: String) -> Vector3` (primeiro nó; `Vector3.INF` se não existe)
- `Regions.area_info(table: Dictionary, id: String) -> Dictionary` com padrões `name = id, level_min = 0,
  level_max = 0, density = 1.0, show_on_map = true`
- `Regions.area_label(table, id) -> String`: `"Toca dos Goblins · Nv 5–9"` (sem faixa: só o nome)
